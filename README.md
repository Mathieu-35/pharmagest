# PharmaGest

Application web de gestion de pharmacie développée avec Django, SQLite (PostgreSQL en production), Bootstrap 5 et ReportLab.

- Cahier des charges : [`docs/cahier-des-charges.docx`](docs/cahier-des-charges.docx)
- Plan de sprints : [`docs/SCRUM.md`](docs/SCRUM.md)

Projet mené en 8 sprints d'une semaine, un sprint ne démarre qu'après la fin du précédent.
